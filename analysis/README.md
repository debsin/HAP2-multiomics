# Analysis scripts

This directory is the code-facing entry point for the HAP2 multi-omics project.

## Published release: Cell Reports Medicine (2026)

The exact computational release associated with the 2026 publication is archived on Zenodo and remains the source of record:

- Zenodo record: https://doi.org/10.5281/zenodo.18768243
- Publication: https://doi.org/10.1016/j.xcrm.2026.102919

To avoid presenting later private-development versions as the published release, the deposited scripts are linked directly from [`published-crm-2026/README.md`](published-crm-2026/README.md).

## Current analysis areas

- longitudinal multi-omics integration and latent-factor modelling;
- cross-cohort comparison and validation;
- interpretable risk modelling;
- respiratory microbiome analysis;
- metabolome–microbiome associations;
- Procrustes / cross-domain concordance analyses;
- supporting kernel-based utilities.

Future HAP2 code that is suitable for public release can be added here as curated analysis modules. The private working repository is intentionally not mirrored wholesale.
