# Analysis scripts

This directory contains curated, publication-relevant computational scripts for the HAP2 multi-omics project.

The archival source of record for the 2026 Cell Reports Medicine release is Zenodo:

- DOI: https://doi.org/10.5281/zenodo.18768243

The scripts added here are intended to be readable, navigable copies of the deposited computational material rather than a mirror of the full private development repository.

## Current analysis areas

- longitudinal multi-omics integration and latent-factor modelling;
- cross-cohort comparison and validation;
- interpretable risk modelling;
- respiratory microbiome analysis;
- metabolome–microbiome associations;
- Procrustes / concordance analyses;
- supporting kernel-based utilities.

For the exact archived release corresponding to the publication, use the Zenodo record.
