# Data access

The de-identified data and archived computational material associated with the published HAP2 multi-omics study are hosted on Zenodo rather than duplicated in this GitHub repository.

**Zenodo DOI:** https://doi.org/10.5281/zenodo.18768243

This separation keeps the GitHub repository lightweight and readable while preserving the Zenodo record as the citable archival source of record.

Please consult the publication and Zenodo record for details on cohort definitions, data availability, and the deposited data objects.
